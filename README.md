## 🧱 Database Schema
The database consists of the following tables:
- **Books** – Contains information about books (title, author, genre, price, stock, etc.)
- **Customers** – Stores customer details (name, country, city, etc.)
- **Orders** – Records all purchase transactions (order date, quantity, total amount)

---

## 🔍 Key SQL Concepts Used
- Data Retrieval using `SELECT`
- Filtering using `WHERE`
- Sorting using `ORDER BY`
- Aggregate Functions (`SUM`, `AVG`, `COUNT`)
- Grouping using `GROUP BY`
- Filtering groups using `HAVING`
- Joins (`INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`)
- Subqueries and data analysis logic

---

## 📊 Analysis Performed

### 🔹 Basic Queries
- Retrieved books by genre (e.g., Fiction)
- Filtered books based on publication year
- Identified customers by location
- Extracted monthly order data
- Calculated total stock and revenue
- Found most expensive and least stocked books

### 🔹 Intermediate & Advanced Queries
- Total books sold per genre
- Average price by genre
- Customers with multiple orders
- Most frequently ordered book
- Top 3 expensive books in a genre
- Total books sold by each author
- Customer spending analysis
- Stock remaining after fulfilling orders

---

## 📈 Key Insights
- Identified high-demand genres and books
- Analyzed customer purchasing behavior
- Determined revenue generation patterns
- Evaluated inventory status after sales
